# Phase 1 implementation decision log

Date: 26 October 2026. Authorization: project owner's request to proceed to the next framework step after carrier/context verification.

- Scope: local full-match XY replay and annotation foundation. No automatic tactical detector or hosted application. Use the Sites skill's local-only workflow and full-story verification guidance.
- Runtime: Python standard-library local server plus buildless HTML/CSS/canvas JavaScript. This avoids forcing unpinned notebook dependencies or remote services into the viewer.
- Input gate: exact Phase 0 file hashes, explicit 20-match local-review configuration, metadata player IDs, byte-indexed native frames. Original Phase 0 eligibility manifest is retained unchanged; local review authorization does not clear publication or model-fitting eligibility.
- Canonical separation: raw tracking carrier, inclusive possession-event candidates, half-open phase labels. Unknown states, event/phase conflicts and multiple candidates remain visible. No nearest-player or forward-fill carrier inference.
- Annotation: reviewer judgement, uncertainty, rationale, frame evidence, defending roles, candidate cues/directions, append-only revisions, quality summaries and implementation/input/configuration provenance. No human labels are claimed until actually supplied.
- Review discipline: provider context off initially; outcomes require explicit separate review. Provider/history/outcome panel exposure is recorded, with prior outcome exposure retained across revisions. This does not establish strict blinding or independence from earlier raw replay.
- Partition: all 20 matches are explicitly development with legacy P1/P2 exposure. No untouched evaluation set was fabricated or silently repurposed.
- Validation: ten software tests, all 20 match loaders with 80 native period-boundary record checks, and desktop/mobile browser flow including the two verified real conflicts. Browser automation annotations used a separate temporary log and were removed afterward.
- Status: Phase 1 software foundation implemented; real analyst labels, review agreement, independent evaluation evidence and Phase 0 release/redistribution questions remain outstanding. The new living framework v0.3 records this state; v0.2 and the frozen charter are preserved.
